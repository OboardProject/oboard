# 架构与生命周期

插件代码仅运行在 Controller 侧独立 `oboard-plugin-worker` 启动的短生命周期 Goja Runner 中。Controller 持有数据库、授权、密钥和 SDK 网关；Worker 经 Controller 所有的 Unix socket 租借执行。Runner 没有数据库、Agent 凭据、任意网络或文件系统 SDK。Agent 只接收既有签名结构化任务，不执行插件 JS。声明式 UI 由 Web 渲染，不加载插件脚本。

## 对象与身份

- `plugin_id`：作者选择的稳定包标识，例如 `acme.node-inspection`，不是数据库数字 ID。
- Plugin：宿主内拥有者、名称与启停状态；宿主资源 ID 在 SDK 中使用十进制字符串。
- PackageVersion / Revision：不可变清单、源码、可选 UI、版本与内容摘要。`version` 是作者版本，`revision_id` 是宿主执行版本，二者不能互换。
- Installation：当前激活版本、已保存配置和安装状态。
- Grant：管理员授予特定内容版本的能力、资源和约束；不是包声明的自动批准。
- TriggerBinding：定时或事件绑定、参数与环境覆盖，固定执行版本。
- Run：持久化输入快照、调用者、版本、租约、状态、日志及结果。
- RunAction：一次宿主 SDK 请求的幂等与下发记录。节点任务完成与 JS 返回是不同事件。
- State / Secret：插件隔离的状态和加密密钥，二者用途不同。

## 安装到执行

1. `pack`/GitHub 获取根入口，静态校验并展示固定内容摘要。
2. 宿主预览身份、权限差异；提交确认绑定所预览摘要。
3. 安装版本但不自动授予能力；按配置 Schema 保存非秘密配置。
4. 管理员授权，启用全局运行环境和插件，再绑定触发器或手动执行。
5. Worker 领取租约；Runner 同步执行 `main()`，每次 SDK 调用在 Controller 重验权限和租约。
6. 保存执行与动作结果。操作 `accepted` 仅表示已接受，不表示目标节点成功。

停用/撤销授权阻止后续调用，不承诺撤回已送达 Agent 或外部服务的动作。租约过期或取消也不是外部动作回滚。版本更新后重新审核，不能用同版本号换代码；恢复数据后不自动恢复调度。

## 扩展边界

SDK 是明确的能力入口，不是任意 REST 代理。管理写入经过现有 Changeset 与业务校验；主控管理员也不能通过插件绕过 Agent 本地安全策略。当前没有 Node.js、多语言运行时、包管理器、常驻插件进程、插件市场、任意前端应用或通用可恢复工作流引擎。请用短任务提交操作并检查回执，不把 JS 阻塞为长期后台守护进程。
